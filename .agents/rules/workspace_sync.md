# 작업 동기화 워크플로우 (Workspace Sync)

사용자가 "오늘 작업 끝" 또는 "작업 시작"을 입력하면 다음 절차를 따르세요.

## 1. "오늘 작업 끝" / "작업 완료" 명령시:
1. 진행한 주요 작업 내용(코드 변경 사항, 남은 이슈 등)을 요약합니다.
2. 루트 디렉토리에 `WORK_SESSION_STATE.md` 파일을 생성(또는 업데이트)하여 요약 내용을 저장합니다.
3. `git add WORK_SESSION_STATE.md` 및 작업된 파일들을 `git commit -m "[Session Sync] 오늘 작업 내역 저장"`으로 커밋하고 `git push origin main`으로 푸시하여 원격 저장소에 백업합니다.
4. 사용자에게 성공적으로 백업되었음을 알리고 수고하셨다고 인사합니다.

## 2. "작업 시작" / "작업 이어하기" 명령시:
1. `git pull origin main`을 실행하여 다른 컴퓨터(데스크톱/노트북)에서 작업한 최신 내용을 가져옵니다.
2. `WORK_SESSION_STATE.md` 파일이 존재하면 읽어서 가장 최근의 작업 상태와 남은 이슈를 파악합니다.
3. 파악한 내용을 바탕으로 "마지막 작업 내용"을 사용자에게 브리핑합니다.
4. "오늘 이어서 진행할 작업이나 목표를 말씀해주세요."라고 안내하며 작업 준비를 마칩니다.

## 3. Git 커밋 전역 규칙 (Global Git Rules)
1. **모든 Git 커밋 메시지는 반드시 "[버전명] 카테고리: 한국어 설명" 형식으로 작성**해야 합니다.
2. 버전을 작성할 때는 반드시 이전 커밋 내역(`git log -n 5`)을 확인하여 **이전 버전에 +1**을 한 넘버링을 적용하세요. (예: 이전 커밋이 `[v1.0.27]`이면 이번 커밋은 `[v1.0.28]`)
3. 카테고리는 `버그 수정`, `기능 추가`, `개선`, `설정` 등 한국어로 명시하세요.
4. 예시: `git commit -m "[v1.0.28] 버그 수정: 이미지 처리 오류 해결"`
